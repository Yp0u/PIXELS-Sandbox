# Changelog

All notable changes to the **PIXELS Sandbox** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses Semantic Versioning (with BETA tags for early development).

## [0.05.000-BETA] - 2026-08-02

This update revolutionizes performance and customization by introducing a 64x64 chunk system, full in-game editors for elements and reactions, global localization, and a massive expansion of the physics and chemistry engines.

### Added
- 🛠️ **In-Game Editor**: Added fully integrated creation and editing tools. You can now build, edit, and fine-tune custom elements, chemical reactions, and layer reactions directly from the game's UI.
- 📦 **Chunk Optimization System**: Implemented a new spatial partition system dividing the world into 64x64 pixel chunks. This drastically improves overall rendering and simulation performance.
- 🌍 **Global Multilingual Support**: The sandbox has been fully localized. Complete translations are now available in 12 different languages.
- ⚛️ **Expanded Element Arsenal**: Added new interactive materials, bringing the total roster to 124 unique elements.
- ⚗️ **Expanded Chemical Engine**: Massively scaled up the chemistry logic, introducing 100 new chemical interactions and bringing the total to 400 unique reactions.
- 🌡️ **Expanded Layer Reactions**: Doubled the complexity of environmental physics (temperature, radiation, pressure, voltage) by adding 200 new layer interactions, reaching a total of 400.

### Fixed
- 🐛 **General Bug Fixes**: Addressed multiple core bugs, corrected specific interaction glitches, and polished overall system stability.

## [0.04.000-BETA] - 2026-07-30

This massive build introduces the highly requested freeze mechanic, a completely improved core structure, a built-in auto-updater, and a gigantic expansion of elements and complex reactions.

### Added
- 🧊 **Freeze & Unfreeze Mechanics**: Ability to freeze (fix) or unfreeze specific elements or all elements simultaneously. Added a dedicated **Freeze Tool** to the brush engine.
- ⚛️ **50 New Interactive Elements**: Expanded element roster from 70 to **120 unique elements**.
- ⚗️ **120 New Chemical Reactions**: Overhauled chemical interactions, bringing the total to **300 unique reactions**.
- 🌡️ **100 New Layer Reactions**: Doubled layer-based reactions (temperature, radiation, pressure, voltage) from 100 to **200 layer reactions**.
- 🔄 **Auto-Updater System**: Added background auto-update functionality for automatic seamless updates without manual downloads.

### Changed
- ⚙️ **Core Architecture Overhaul**: Heavily optimized and restructured core engine for better stability, scalability, and overall performance.

## [0.03.050-BETA] - 2026-07-28

This release significantly expands both the simulation engine and the user experience.

### Added
- **10 new interactive elements**, including:
  - 🔥 Heat Generator
  - ☢️ Enriched Uranium
  - ⚡ Superconductor

  - 🧨 C4 Explosive
